FUNDAMENTAL CONCEPTS

Instruction คืออะไร?

Instruction = คำสั่งที่บอก CPU ว่าให้ทำอะไร — แต่ CPU ไม่เข้าใจคำว่า add ตรง ๆ

ตัวอย่าง · add $t0, $t1, $t2
$t1 + $t2 → $t0

$t0 = $t1 + $t2 — นำข้อมูลใน $t1 กับ $t2 มาบวกกัน แล้วเก็บผลลัพธ์ไว้ที่ $t0

FLOW · ภาษาระดับสูง → CPU
Assembly add $t0, $t1, $t2
Machine Language 000000 01001 01010 01000 00000 100000
CPU อ่าน 32 bits แล้วทำตาม
จำแบบนี้สุดท้ายแล้วคำสั่งถูกเก็บเป็น Binary 32 bits — MIPS จึงต้องกำหนดว่าทั้ง 32 bits แต่ละตำแหน่งเก็บอะไรบ้าง นั่นคือ Instruction Format

MIPS INSTRUCTION FORMATS

MIPS มี 3 รูปแบบหลัก ⭐ จำ 3 ตัวนี้ก่อนเลย

ทุกคำสั่ง MIPS ตกอยู่ในรูปแบบใดรูปแบบหนึ่งจากทั้งหมด 3 รูปแบบนี้

R

R = Register

R-Format

คำนวณระหว่าง Register
add · sub · slt

I

I = Immediate

I-Format

มีตัวเลข / Memory / Branch
addi · lw · sw · beq · bne

J

J = Jump

J-Format

กระโดดไปตำแหน่งอื่น
j · jal

จำประโยคนี้ให้ขึ้นใจ R = Register · I = Immediate · J = Jump

FORMAT 1 · R-FORMAT ⭐⭐⭐

R-Format — โครงสร้าง

ใช้กับคำสั่งที่ทำงานกับ Register เป็นหลัก — 6 ช่องรวมกันเป็น 32 bits

R-FORMAT · 32 BITS
opcode6 bits
rs5 bits
rt5 bits
rd5 bits
shamt5 bits
funct6 bits
opcode(6) + rs(5) + rt(5) + rd(5) + shamt(5) + funct(6)= 32 bits

ตัวอย่าง

add $t0, $t1, $t2 — opcode = 0 และ funct = 32 (สำหรับ add) ช่องอื่นบอกว่าใช้ Register ตัวไหน

รวมต้องได้ 32

6 + 5 + 5 + 5 + 5 + 6 = 32 bits = 4 bytes — ทุกคำสั่ง MIPS มีขนาดเท่ากันเสมอ

FORMAT 1 · R-FORMAT

แต่ละช่องของ R-Format มีหน้าที่อะไร?

ดูจากตัวอย่าง add $t0, $t1, $t2 — add rd, rs, rt หรือ rd = rs + rt

6b

opcode

Operation Code — บอกว่าคำสั่งประเภทไหน เช่น R-Format ใช้ opcode = 0 แล้วให้ funct ช่วยบอกคำสั่งที่แน่นอน

5b

rs

Register ตัวที่ 1 (input) — ใน add $t0,$t1,$t2 ตัวนี้คือ $t1

5b

rt

Register ตัวที่ 2 (input) — จากตัวอย่างคือ $t2

5b

rd

Register ปลายทาง — ที่เก็บผลลัพธ์ จากตัวอย่างคือ $t0

5b

shamt

Shift Amount — บอกว่าจะ Shift กี่ตำแหน่ง เจอในคำสั่ง Shift เช่น sll

6b

funct

Function — ระบุ operation ที่แน่นอน เช่น add, sub → ต้องดูทั้ง opcode + funct

FORMAT 1 · R-FORMAT

ตัวอย่าง R-Format — add $8, $9, $10

ความหมายคือ $8 = $9 + $10 — เอาค่าใน $9 กับ $10 มาบวกกัน เก็บผลลัพธ์ที่ $8

ADD $8, $9, $10 · จับคู่ช่องแต่ละฟิลด์
opcode0
rs9
rt10
rd8
shamt0
funct32
rs = 9 · rt = 10 · rd = 8 · opcode = 0 · funct = 32 (add)32 bits
จำง่ายสุด add rd, rs, rt → rd = rs + rt — rd มาก่อนเสมอ!

FORMAT 2 · I-FORMAT ⭐⭐⭐

I-Format — โครงสร้าง

I = Immediate — มีค่าตัวเลขฝังอยู่ในคำสั่ง จึงมีช่อง immediate 16 bits

I-FORMAT · 32 BITS
opcode6 bits
rs5 bits
rt5 bits
immediate16 bits
opcode(6) + rs(5) + rt(5) + immediate(16)= 32 bits

คำสั่งกลุ่ม I-Format

addi · lw · sw · beq · bne — คำสั่งที่มี Immediate / Offset / Branch displacement

รวมต้องได้ 32

6 + 5 + 5 + 16 = 32 bits — immediate กินเนื้อที่เยอะสุด (16 bits)

FORMAT 2 · I-FORMAT

Immediate คืออะไร?

Immediate = ค่าตัวเลขที่อยู่ในคำสั่งโดยตรง — ไม่ต้องไปเอาจาก Register

ADDI $t0, $t1, 10
$t1 + 10 → $t0

ตรงนี้ 10 คือ Immediate → $t0 = $t1 + 10

ทำไมต้องมี immediate?เพราะบางครั้งเราก็แค่อยากบวกค่าคงที่ — ฝังเลข 10 ไว้ในคำสั่งเลย ไม่ต้องเสียเวลาโหลดจาก Register หรือ Memory

FORMAT 2 · I-FORMAT

ตัวอย่าง I-Format — addi $21, $22, -50

หมายถึง $21 = $22 + (-50) — สังเกตว่า addi ใช้ Immediate จึงเป็น I-Format

ADDI $21, $22, -50 · จับคู่ช่องแต่ละฟิลด์
opcodeaddi
rs$22
rt$21
immediate-50
rs = $22 · rt = $21 · immediate = -50$21 = $22 + (-50)
ระวัง!ใน addi ตัวที่อยู่หน้าสุด ($21) คือ rt ไม่ใช่ rd — เพราะ I-Format ไม่มีช่อง rd

FORMAT 2 · I-FORMAT

คำสั่งที่ใช้ I-Format ที่ควรรู้

จำกลุ่มหลัก 5 ตัวนี้ — เพราะมี Immediate / Offset / Branch displacement อยู่ในรูปแบบ I-Format

addi

Add Immediate — $rt = $rs + immediate เช่น addi $t0,$t1,10

lw

Load Word — โหลดจาก Memory เข้า Register ใช้ offset 16 บิต

sw

Store Word — เก็บจาก Register ลง Memory ใช้ offset 16 บิต

beq

Branch if EQual — กระโดดถ้า rs == rt ใช้ branch displacement

bne

Branch if Not Equal — กระโดดถ้า rs != rt

immediate / offset

ค่าคงที่ 16 bits ที่ฝังในคำสั่ง — ใช้เป็นตัวเลข บวก/ลบ หรือ offset ของ Memory

FORMAT 2 · I-FORMAT

I-Format กับ Memory — lw / sw

lw = โหลดจาก Memory เข้า Register · sw = เก็บจาก Register ลง Memory

LW $t0, 4($s1) · Memory → Register
Memory
$s1 + 4 → $t0

ไปที่ Memory โดยใช้ $s1 เป็นจุดเริ่มต้น + offset 4 แล้วโหลดข้อมูลมาใส่ $t0

SW $t0, 4($s1) · Register → Memory
$t0 → Memory
$s1 + 4

เอาข้อมูลจาก $t0 ไปเก็บใน Memory ที่ตำแหน่ง offset 4 จาก $s1

จำคู่นี้ lw = Memory → Register · sw = Register → Memory — l มา (Load) ก่อน s (Store)

FORMAT 3 · J-FORMAT ⭐⭐

J-Format — โครงสร้าง

J = Jump — ใช้กับคำสั่งกระโดดไปตำแหน่งอื่น เช่น j label และ jal function

J-FORMAT · 32 BITS
opcode6 bits
target address26 bits
opcode(6) + target address(26)= 32 bits

j label

Jump — กระโดดไปที่ตำแหน่งของ label โดยไม่สนใจเงื่อนไข

jal function

Jump And Link — เก็บตำแหน่งที่จะกลับ แล้วกระโดดไป function

FORMAT 3 · J-FORMAT

j คืออะไร? (Jump)

j Loop = กระโดดไปที่ตำแหน่งของ Loop — ไม่ได้สนใจว่าเงื่อนไขเป็นจริงหรือไม่

ตัวอย่าง · J LOOP
คำสั่งก่อนหน้า
j Loop กระโดดไปที่ Loop
Loop: คำสั่งต่อไปที่ CPU จะทำ
จำแบบนี้ j = Jump — กระโดดแบบไม่มีเงื่อนไข ไม่เก็บอะไรไว้สำหรับกลับมา

FORMAT 3 · J-FORMAT

jal คืออะไร? (Jump And Link)

jal ทำ 2 อย่าง — เก็บ Address กลับไว้ที่ $ra แล้ว กระโดดไป function

STEP 1 · เก็บตำแหน่งที่จะกลับ
Address ของคำสั่งถัดไป ถูกเก็บไว้ใน $ra (Return Address)
เช่น ถ้าคำสั่ง jal อยู่ที่ 1000 → $ra = 1004 (คำสั่งถัดไป)
STEP 2 · กระโดดไป Function
jal sum → CPU กระโดดไปยังคำสั่งแรกของ sum
เมื่อ function ทำงานเสร็จ ใช้ jr $ra กลับมาทำต่อจากที่เดิม
ต่างจาก j ยังไง?j กระโดดอย่างเดียว (ไปแล้วไม่กลับ) · jal จำไว้เสมอว่าจะต้องกลับมาที่ไหน (เก็บที่ $ra)

MEMORY & DATA ⭐⭐⭐

Memory & Data ใน MIPS

โปรแกรมมี 2 ส่วน — .text (คำสั่ง) และ .data (ข้อมูล) — la ใช้โหลด Address ของ label

ไดเรกทีฟข้อมูล
.word 0xabcd1234 — ข้อมูล 1 คำ 4 bytes
.byte 11,12,13 — ข้อมูล 1 byte ต่อตัว ไล่เรียงกัน
la t0, myDat — เอาตำแหน่งของ label myDat ใส่ $t0
จับมือเก็บ LITTLE-ENDIAN · 0xabcd1234
1. เขียนเลขเป็นคู่ ๆ: ab cd 12 34 (จากซ้ายไปขวา)
2. little-endian = เอา byte ท้ายสุดมาก่อน: เริ่มจาก 34 ไปจนถึง ab
3. เก็บเรียงลง Memory: 34 12 cd ab — ตัวแรกที่เจอ = 0x34

LOAD INSTRUCTIONS ⭐⭐⭐

lb / lbu / lw — การโหลดข้อมูล

lw โหลด 4 bytes (ต้องจัดตำแหน่ง) · lb กับ lbu โหลด 1 byte — ต่างกันที่การขยายเครื่องหมาย

SIGN-EXTEND vs ZERO-EXTEND (โหลด byte → 32 bits)
คำสั่งโหลดขยายผลลัพธ์
lw4 bytes (1 word)—32 bits เต็ม
lb1 bytesign-extend (เติมตาม bit เครื่องหมาย)0x34 → 0x00000034 · 0xab → 0xffffffab
lbu1 bytezero-extend (เติม 0 หน้าเสมอ)0xcd → 0x000000cd

lb — sign-extend (จับมือ)

1. โหลด 1 byte เช่น 0xab = 1010 1011
2. ดูบิตซ้ายสุด (MSB) = 1 → เติมเลข 1 หน้า 24 ตัว
3. ได้ 1111...1010 1011 = 0xffffffab (ค่าลบ)

ถ้า MSB = 0 (เช่น 0x34) → เติม 0 → 0x00000034 (บวก)

lbu — zero-extend (จับมือ)

1. โหลด 1 byte เช่น 0xcd = 1100 1101
2. เติม 0 หน้า 24 ตัวเสมอ (ไม่ดู MSB)
3. ได้ 0000...1100 1101 = 0x000000cd (บวกเสมอ)

เหมาะกับข้อมูลที่อยากได้ค่า unsigned (0..255)

สรุปบทเรียน

เก็บทุกประเด็นสำคัญของบทนี้ไว้ในหน้าเดียว

32 bits

ทุกคำสั่ง MIPS มีขนาดคงที่ 32 bits = 4 bytes

R-Format

opcode|rs|rt|rd|shamt|funct · add, sub, slt · rd = rs + rt

I-Format

opcode|rs|rt|immediate · addi, lw, sw, beq, bne

J-Format

opcode|target address · j, jal (jal เก็บ $ra)

.word / .byte

.word = 4 bytes · .byte = 1 byte · la เอา address ของ label

Little-endian

0xabcd1234 เก็บเป็น 34 12 cd ab — byte ต่ำมาก่อน

lb vs lbu

lb = sign-extend · lbu = zero-extend · lw = 4 bytes

q1t8.asm

s0=0, s1=0x34, s2=0x12, s3=0xcd, s4=0, s5=0xffffffab, s6=0x12, s7=0

จำแบบนี้R = Register · I = Immediate · J = Jump — และ lw = Memory→Register, sw = Register→Memory
